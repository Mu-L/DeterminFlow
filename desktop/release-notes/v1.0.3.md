DeterminFlow 1.0.3 统一提升默认模型上下文，并更新 Full 安装包中的官方 Plugin 快照。

- Chat Main 和其他通用模型调用在未显式配置时，默认使用 128K 上下文，不再回退到 8K。
- 模型 Provider 设置现在会正确保存 `maxContextTokens`；用户显式配置的模型或 Provider 值仍然优先。
- 压缩检查、Session Token 状态、桌面默认配置和前端 Prompt 预览统一使用同一 128K 默认值。
- Full 安装包携带 Bishu Novel 0.2.2，写作助手默认启用并自动注入 Chat Main；Core 安装包仍保持纯净。
- Core 与 Full 继续共用 Core 更新通道；Plugin 版本、配置和数据仍独立更新并保持不变。
- 服务版入口继续使用仓库根目录的 `python run.py`，不初始化桌面更新功能。

本版本不会迁移或覆盖已有用户的 `models_config.json`；已有显式配置保持原值，缺少上下文字段时使用新的 128K 回退值。

已知限制：安装包尚未使用 Windows Authenticode（代码签名）；Shell Workflow 仍需要用户
自行安装 Git Bash，Plugin 在线更新当前仍依赖系统 Git。
