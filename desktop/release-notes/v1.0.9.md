DeterminFlow 1.0.9 改善 Workflow 输出可靠性与复杂分支执行，并扩充 Full 安装包的公益能力。

- Agent 节点可要求最后一条 LLM 输出非空，或校验 JSON 字符串字段的最小字数；校验失败由既有节点自动重试策略处理，且不会留下部分输出变量或文件副作用。
- 条件分支内嵌套并行网关时，会保留真实并行执行与汇合语义；任务恢复继续沿用已冻结的分支选择和已完成节点。
- Full 安装包除 `bishu-novel` 外，同时预装并启用 `public-api` 公益模型客户端 Plugin；Core 安装包仍不捆绑任何官方 Plugin。

本版本不迁移或覆盖已有 Workflow、Task、Workspace、Plugin、模型配置和用户数据。`public-api` 只包含公开客户端能力；账号、额度、风险治理、模型转发、支付、凭据签发、生产配置与 Secret 等服务端实现不包含在开源仓库和安装包中。

已知限制：安装包尚未使用 Windows Authenticode（代码签名）；Shell Workflow 仍需要用户自行安装 Git Bash，Plugin 在线更新当前仍依赖系统 Git。
