DeterminFlow 1.0.2 修复 Windows 桌面后端进程在关闭或更新后残留的问题。

- 正常关闭桌面窗口时同步结束内置后端进程树并等待退出。
- 自动更新启动安装器前执行同一套后端清理，避免安装目录文件被锁定。
- Single Instance（单实例）保护提前到首个 Tauri Plugin 初始化，阻止重复启动第二套后端。
- NSIS 安装和卸载在复制或删除文件前清理同名遗留后端，覆盖异常退出后的恢复路径。
- Core 与 Full 继续共用 Core 更新通道；Full 只在首次安装时携带公开官方 Plugin 快照。

已知限制：安装包尚未使用 Windows Authenticode（代码签名）；Shell Workflow 仍需要用户
自行安装 Git Bash，Plugin 在线更新当前仍依赖系统 Git。
