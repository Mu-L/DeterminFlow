DeterminFlow 1.0.5 减少 Main 等待 Sub Agent 和 Workflow Task 时的重复轮询。

- `check_sub_progress`、`get_task_status` 和 `get_task_result` 支持等待状态变化，或等待终态及需要 Main 介入的状态。
- 等待可以设置最长秒数；`timeout_seconds=null` 表示不设截止时间，同时保留取消能力。
- Workflow 完成、失败、停止或取消时会自动返回；未启动或等待审批时会提前交还控制权，避免 Main 无法继续启动或审批。
- `get_task_result` 可以在同一次调用中等待并返回最终结果，不再要求终态后追加一次查询。
- Sub Agent 终态会返回有长度上限的 `final_output`，Main 可以直接核对并整合结果。
- Main 默认 Prompt 新增一条明确的 Workflow Task 最优执行路径，默认使用隔离工作空间、完整 TaskRef 和事件驱动结果等待。

本版本不迁移或覆盖已有 Workflow、Task、Session、Plugin、模型配置和用户数据。服务版入口继续使用仓库根目录的 `python run.py`，不会初始化桌面更新功能。

已知限制：安装包尚未使用 Windows Authenticode（代码签名）；Shell Workflow 仍需要用户自行安装 Git Bash，Plugin 在线更新当前仍依赖系统 Git。
