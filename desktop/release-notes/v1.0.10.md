# DeterminFlow v1.0.10

- Windows Workflow Runtime 默认使用 4 个独立 Executor 进程，支持同一 Workflow Task 及其节点重试、打回继续固定在同一 Executor，并补充进程恢复、状态观测与真实并发场景验证。
- Windows Full 安装包携带发行准备时最新且已验证的公开官方 Plugin，并以绑定桌面版本的精确 Commit 构建锁保证同版本重建不会随 `main` 漂移。
- Full 当前锁定 `bishu-novel 0.2.2` 与 `public-api 0.1.33`；公益模型客户端包含独立公告、余额档位和完整模型目录。Core 安装包仍不捆绑任何 Plugin。

本版本不覆盖已有 Workflow、Task、Workspace、Plugin、模型配置或用户数据。Full 初始快照不依赖 Git；后续从 Plugin 页面在线更新仍需要系统可用的 Git。
