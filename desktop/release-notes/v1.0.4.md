DeterminFlow 1.0.4 为 Core 和官方 Plugin 更新加入 GitHub / Gitee 双源选择。

- Windows 桌面端会并行检查 GitHub 与 Gitee 更新源；不同版本优先选择较新版本，同一版本选择响应更快的来源。
- 任一更新源不可用时会自动使用另一个来源，下载与安装仍沿用 Tauri 的签名校验流程。
- 官方 Plugin 仓库新增 Gitee 镜像；主源可达时只在相同 commit 的地址中按响应速度选择，避免镜像同步延迟导致回退到旧版本。
- Plugin 主源不可达时会使用最快的可用镜像；安装锁仍记录 GitHub 主地址，镜像只承担传输。
- 新增手动 Gitee 同步脚本，可同步 Core、Plugin 代码和标签，并把 GitHub Release 构建产物复制到 Gitee Release。

本版本不修改已有 Plugin、Workflow、模型或用户数据。服务版入口继续使用仓库根目录的 `python run.py`，不会初始化桌面更新功能。

已知限制：Gitee Release 不会由仓库镜像自动同步，需在 GitHub Release 构建完成后手动运行同步脚本；安装包尚未使用 Windows Authenticode（代码签名）；Shell Workflow 仍需要用户自行安装 Git Bash，Plugin 在线更新当前仍依赖系统 Git。
