DeterminFlow 1.0.6 为 Chat 增加内联文件附件，并补齐社区版 Runtime 与 Plugin 安装修复。

- Chat 输入框支持选择文件或拖入文件，附件以可移动、可删除的气泡插入消息；浏览器上传会把文件保存到当前 Session Workspace，Windows 桌面版可直接使用本地文件路径。
- 输入框改进展开、收起、键盘发送和附件上传反馈；历史消息会保留附件元数据，刷新或重新打开会话后仍显示文件气泡。
- Session 启动改用轻量目录和有界历史缓存，终态 Workflow 在严格保存后释放运行期对象，降低大量历史 Session 的常驻内存。
- Workflow Workspace 使用统一路径解析，服务运行数据目录和受控外部数据目录采用相同安全边界。
- Plugin 安装可正确验证 Catalog 锁定的 exact commit，修复 GitHub 与 Gitee 均可访问时仍可能返回 API 400 的问题；官方镜像也不能再被重复保存为自定义仓库。
- 社区版补齐持久化 Workflow 准入状态及相关恢复机制，便于服务维护期间停止接收新 Task，同时保留查询、恢复和现有任务处理能力。
本版本不迁移或覆盖已有 Workflow、Task、Session、Workspace、Plugin、模型配置和用户数据。服务版入口继续使用仓库根目录的 `python run.py`，不会初始化桌面更新功能。

已知限制：安装包尚未使用 Windows Authenticode（代码签名）；Shell Workflow 仍需要用户自行安装 Git Bash，Plugin 在线更新当前仍依赖系统 Git。
