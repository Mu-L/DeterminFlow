DeterminFlow 1.0.1 是首个 Windows 桌面正式发行版。

- 提供 Core 与 Full 两个 NSIS 安装包；两者使用同一 Core 版本和更新通道。
- Full 安装包在构建时快照全部公开官方 Plugin，并在首次启动时预装、启用；后续 Plugin 继续通过 Plugin 页面独立更新（当前仍依赖系统 Git）。
- 桌面端每天至多静默检查一次 Core 更新，发现新版本后由用户确认安装并重启。
- 服务版入口保持为仓库根目录的 `python run.py`，不初始化桌面更新功能。

已知限制：安装包尚未使用 Windows Authenticode（代码签名），SmartScreen 提示取决于设备信誉；Shell Workflow 仍需要用户自行安装 Git Bash。
